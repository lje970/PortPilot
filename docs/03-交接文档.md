## 3. 🔨 M2 精确断点(接手第一件事)

### 已完成
1. **core 层网络传输**(`src/crates/portpilot-core/src/transport.rs`):`TransportKind`(Serial/TcpClient/TcpServer/Udp)+ `open_transport()` 统一入口;TCP 客户端(读超时+EOF 断连)、TCP 服务端(单客户端,断开自动回监听)、UDP(绑定收 + remote/最后来源发)。**25 单测全过(含 localhost 三传输实测)**。
2. **app 后端**:connect 命令带 `kind`/`remote` 参数;日志回放命令组(list_logs/replay/replay_stop,独立 replays 状态表,33ms 节流按倍速推送)。
3. **前端**:连接栏传输类型下拉(串口/TCP客户端/TCP服务端/UDP,控件切换)+ 地址/UDP remote 输入 + 回放模态(文件列表/倍速/停止)+ 档案带网络参数。
4. **刚修复未验证的 bug**:冒烟判定 `smoke = port && baud>0 && seconds>0` 要求 baud>0,但 TCP 冒烟命令不带 `--baud` → smoke=false → **单实例插件把冒烟进程静默拦截(exit 0 无输出)**。已改为"仅串口要求 baud"。**已重新构建成功,尚未跑 TCP 冒烟验证**。

### ⚠️ 接手第一步:TCP 冒烟验证(命令已备好)
```bash

taskkill //F //IM portpilot-app.exe
# 1) 启动 python TCP 灌流服务端(后台,监听 45997,发 5 秒)
# 2) 冒烟(注意 --kind tcp_client,现在不强制 --baud):
```

## 7. 踩坑清单(照抄不踩)

1. **Git Bash 的 `usr/bin/link.exe` 遮蔽 MSVC link** → 必须 vcvars64 会话构建;`src/app/src-tauri/.cargo/config.toml` 已显式指定 linker。
2. **Tauri 2 ACL**:前端 `listen()` 默认被拒 → `capabilities/default.json` 必须声明 `core:event:allow-listen` 等。
3. **WebView emit 堆竞争**会拖垮 I/O 线程(G1 实测丢 5.6%)→ 核心层 I/O 线程免分配 SPSC 环 + 背压自旋,产品红线。
4. **serialport 枚举 API**:match `p.port_type`(不是 match 整个 info),此坑已踩 3 次。
5. **双实例抢串口** → 重连风暴(500ms 频率)→ 已加 single-instance 插件(CLI 冒烟豁免);冒烟判定别再要求 baud(网络传输无波特率)。
6. **多标签重构时给终端外包了 `#termHost` 却没接弹性链** → 终端把示波器/发送栏顶出窗口(flex:1 + min-height:0 已修)。
7. **app.js / main.rs 会被外部格式化器改动**(用户环境),Edit 工具易冲突 → 大段修改优先 python 锚点补丁,改前先 grep 确认现状。
8. release 版无 DevTools → 前端已埋 JS 错误捕获(错误打进终端黄色系统行),排障先看终端首屏。
9. Windows 串口独占:测试前 `tasklist | grep portpilot` 查残留,`taskkill //F //IM portpilot-app.exe`。
