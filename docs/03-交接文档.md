## 7. 踩坑清单(照抄不踩)

1. **Git Bash 的 `usr/bin/link.exe` 遮蔽 MSVC link** → 必须 vcvars64 会话构建;`src/app/src-tauri/.cargo/config.toml` 已显式指定 linker。
2. **Tauri 2 ACL**:前端 `listen()` 默认被拒 → `capabilities/default.json` 必须声明 `core:event:allow-listen` 等。
3. **WebView emit 堆竞争**会拖垮 I/O 线程(G1 实测丢 5.6%)→ 核心层 I/O 线程免分配 SPSC 环 + 背压自旋,产品红线。
4. **serialport 枚举 API**:match `p.port_type`(不是 match 整个 info),此坑已踩 3 次。
5. **双实例抢串口** → 重连风暴(500ms 频率)→ 已加 single-instance 插件(CLI 冒烟豁免);冒烟判定别再要求 baud(网络传输无波特率)。
6. **多标签重构时给终端外包了 `#termHost` 却没接弹性链** → 终端把示波器/发送栏顶出窗口(flex:1 + min-height:0 已修)。
7. **app.js / main.rs 会被外部格式化器改动**(用户环境),Edit 工具易冲突 → 大段修改优先 python 锚点补丁,改前先 grep 确认现状。
8. release 版无 DevTools → 前端已埋 JS 错误捕获(错误打进终端黄色系统行),排障先看终端首屏。
9. Windows 串口独占:测试前 `tasklist | grep portpilot` 查残留,`taskkill //F //IM portpilot-app.exe`。
10. **PowerShell here-string 写 manifest**:`$var` 在双引号 here-string 中若行尾跟 `:` 等符号可能被吞(实测 InstallerUrl 写出空值)→ 关键 URL 字段直接内联字面量,或生成后 grep 断言非空。
11. **Windows PowerShell 5 的 `Set-Content -Encoding UTF8` 带 BOM**,winget yaml/json 均拒绝 → 用 `[IO.File]::WriteAllText($p,$s,(New-Object Text.UTF8Encoding($false)))`。
12. **winget 1.12 schema 三坑**:①version manifest 必须有 `DefaultLocale: en-US`;②`InstallerType: zip` 要放 Installer 条目内(非顶层);③中文 locale 文件在 WinPS 管道下易乱码破坏 YAML → defaultLocale 用 en-US 纯 ASCII。CI(Checks 02)比本地 `winget validate` 严,提交前先本地 validate 一次再推。
13. **Compress-Archive zip 条目名乱码**:中文文件名(使用说明.txt)入 zip 后变 mojibake → 改用 `[IO.Compression.ZipFile]::CreateFromDirectory($stage,$zip,'Optimal',$true,[Text.Encoding]::UTF8)` 显式 UTF-8。⚠️ 重打包后 zip hash 变更:`a95fd88365c56a504d2812c40035af28a169b09ffc0d36a3383ee4c38d68d96b`;**winget PR #468756 的 InstallerSha256 还是旧 zip 的 c21295e5…,Release 资源若替换新 zip,须同步更新 manifest hash 并推 PR 分支,否则 03 URL 验证会挂**。当前 Release 上仍是旧 hash 的 zip(功能无差,仅说明文件名编码),两 zip 皆可用。

## 9. 架构与数据流(读懂代码的钥匙)

```
┌─────────────────────────── Rust 侧(src/app/src-tauri)───────────────────────────┐
│ UI 命令(connect/send/set_rules…) ──> AppState                                      │
│   sessions: HashMap<tab, SessionEntry>   ← 多标签,每标签独立会话/编码/解析器      │
│   rules / scope_on / replays              ← 全局规则表/示波器开关/回放标志         │
│                                                                                   │
│ 每个会话两条线程(核心层 src/crates/portpilot-core):                              │
│   I/O 线程:Transport(串口/TCP/UDP)阻塞读 → SPSC 环(免分配) ←断线自动重连        │
│   泵线程(33ms):drain 环 → ①原始日志落盘 logs/*.bin ②按编码逐行解码组装           │
│                 ③规则引擎匹配(命中→write 回发,300ms 冷却)                        │
│                 ④示波器抽头(ScopeParser 喂字节→JustFloat/CSV 帧)                 │
│                 ⑤emit "rx"/"scope" 事件(带 tab 路由)                              │
└───────────────────────────────────────────────────────────────────────────────────┘
┌─────────────────── 前端(src/app/ui,原生 JS 无框架)──────────────────────────────┐
│ listen('rx') 按 d.tab 路由到对应 VirtualLog;                                      │
│ VirtualLog(文本+HEX 双实例/标签):全量存内存(上限 100 万行,超出批量丢旧计数),     │
│   只渲染视窗 ±10 行(定高 18px,DOM 池复用);过滤=包含/排除+re:正则,命中 <mark>     │
│ 标签页各自独立:过滤条件/暂停态/视图;连接档案/发送历史/快捷按钮 → localStorage     │
└───────────────────────────────────────────────────────────────────────────────────┘
```

**性能红线**(实测得出,重构不可破坏):I/O 线程热路径零堆分配;泵线程是唯一 emit 点(33ms 节流);UI 永不直接触碰 Transport;SPSC 环满时 I/O 侧自旋等待(背压计数),不丢数据。

## 10. 代码导览(按阅读顺序)

| 文件 | 职责 | 关键点 |
|---|---|---|
| `core/src/ring.rs` | 无锁 SPSC 字节环 | UnsafeCell + acquire/release;**只有单写单读两线程可共享** |
| `core/src/transport.rs` | Transport trait + 4 种实现 | trait 含 read/write/close/set_dtr/set_rts;TCP 服务端单客户端语义(断开回监听);UDP 无 remote 时回复最后来源 |
| `core/src/session.rs` | 会话线程 + SessionHandle | 工厂模式(重连时重建 Transport);`write/set_dtr/set_rts` 经共享槽 `Arc<Mutex<Option<Box<dyn Transport>>>>`(读 5ms 一轮、写低频,锁竞争可忽略);瞬时读错误容忍=连续 3 次;测试用 ScriptedTransport 注入 |
| `core/src/crc.rs` | 7 种校验和 | 标准向量测试("123456789");append_checksum 支持大小端 |
| `core/src/scope.rs` | JustFloat/CSV 解析 | JustFloat 找尾 `00 00 80 7F` 对齐,垃圾前缀滑动重同步,4MB 防御上限 |
| `app/src-tauri/src/main.rs` | 全部命令 + 泵线程 | Rule 引擎(eval 带 300ms 冷却);replay 独立 replays 表(不占 sessions);CLI 冒烟(--port/--kind/--baud/--seconds/--out,看门狗线程强制退出) |
| `app/ui/app.js` | 前端全部逻辑 | 顶部有全局 JS 错误捕获(release 无 DevTools,错误进终端黄行);`__PP_sysLine` 桥 |
| `bench/` | 基准量尺 | loopback_test(--pair/--loop/--tx-only/--rx-only/--selftest)、run_matrix、run_poc_test(四栈统一跑台)、mcu_firmware/(灌流+示波器固件) |

## 12. P1 功能速查(给测试者/接手者)

- **规则表**:📋 规则 → 每行 `[启用][文本/HEX/正则][关键词][发送内容][HEX][新行]` → 保存即全局生效(localStorage 持久化);命中冷却 300ms 防风暴。
- **示波器**:📈 → 协议(JustFloat/CSV)+ 通道数 + **启用抽头** → canvas 自适应 Y 轴;配 `bench/mcu_firmware/esp32_justfloat_pio` 固件(2 通道正弦 100Hz)联调;CSV 模式任何 printf 浮点行的板子都能画。
- **CRC**:发送栏选校验类型+字节序,输入时实时预览,发送自动追加。
- **多标签**:+ 新建;标签名连接后自动变 `COM9@460800` / `TCP 1.2.3.4:8080`;✕ 关闭自动断开。
- **回放**(M2 新增):⏵ 回放 → 选 logs/*.bin → 倍速(1×=460800 线速)→ 回放到当前标签。
